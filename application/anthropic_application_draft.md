## What the project does

MemDeviceBench is a topology- and mechanism-aware data standard and Python analysis toolkit for memory and adaptive electronic devices. It supports RRAM/ReRAM, PRAM/PCM, FRAM, FeFET, ECRAM, CBRAM, MRAM, TFT, OECT, memtransistors, and related technologies through independent tags for technology, accessible terminal count, platform, physical mechanism, material, observed behavior, and experiment profile.

The current validated core standardizes pulse-by-pulse conductance-update data, reports transparent update/retention/endurance metrics, and prevents a common physical error: estimating programming energy for a 3- or 4-terminal device from channel read conductance when programming-path current was not measured.
