# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socioeconomic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Our standards

Examples of positive behavior include using welcoming language, respecting differing viewpoints, accepting constructive criticism, focusing on what is best for the community, and showing empathy toward others.

Unacceptable behavior includes sexualized language or imagery, trolling, insulting comments, public or private harassment, publishing others' private information without permission, and conduct that could reasonably be considered inappropriate in a professional setting.

## Enforcement

Report unacceptable behavior privately to the maintainer contact listed in the repository security settings. Project maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that are not aligned with this Code of Conduct.

This text is adapted from Contributor Covenant 2.1.
